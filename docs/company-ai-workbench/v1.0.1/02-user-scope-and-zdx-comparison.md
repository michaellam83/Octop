# 普通用户能力范围与智多星原生 Web 对比

## 1. 普通用户当前可以做什么

| 功能 | 当前范围 | 说明 |
| --- | --- | --- |
| 登录与会话 | 支持 | 由管理员创建用户或按一期已有初始化流程进入系统。 |
| Web 对话 | 支持 | 可以创建、切换和查看自己的会话。 |
| 普通专家 | 支持 | 使用管理员允许的 Provider、模型、技能、连接器、知识库和工具。 |
| 通联发仔 | 支持 | 使用当前用户自己的智多星 userid/key；不可切换为普通模型。 |
| 公网搜索 | 间接支持 | 由管理员配置公共搜索 Provider 后，通联发仔按问题类型触发检索。 |
| Token 统计 | 支持 | 普通专家和通联发仔的用量纳入当前用户可见统计范围。 |
| 个性化配置 | 支持 | 可以维护普通专家可用的个人偏好；托管专家的管理员模板不由用户覆盖。 |
| 通道对话 | 按配置支持 | 已绑定并授权的 QQ 等通道可以进入相同的用户/专家路由。 |
| 附件、技能、连接器、知识库 | 普通专家支持 | 是否可用仍取决于管理员授权、存储配置和具体专家；不属于通联发仔能力。 |
| 自动化 | 一期普通用户隐藏 | 当前交互和使用闭环尚未作为一期验收能力，后续优化后再开放。 |

## 2. 普通用户当前不能管理什么

- 不能创建或删除其他用户，不能修改角色和权限。
- 不能查看或读取其他用户的智多星 userid/key。
- 不能配置公共模型 Provider、Tavily 等公共搜索凭据、公共存储和全局插件。
- 不能修改托管模板，也不能把普通技能、连接器或知识库强行注入通联发仔。
- 不能在通联发仔中切换普通专家、执行普通快捷指令、使用普通工作区或直接调用其他专家。
- 不能将通联发仔的专用智多星配置当成普通专家的公共默认模型。

## 3. 与智多星原生 Web 的定位对比

| 维度 | AllinpayAI 当前版本 | 智多星原生 Web |
| --- | --- | --- |
| 核心定位 | 企业内部统一工作台，把通联业务、普通 AI 专家和多通道入口放在一个系统中。 | 智多星平台原生的模型和业务查询入口。 |
| 用户体系 | 支持管理员、普通用户、用户级凭据隔离和统一权限管理。 | 以智多星平台自身的账号、套餐和权限体系为准。 |
| 通联发仔 | 每个用户用自己的 userid/key，通过托管模板统一提示词、时间处理和公网搜索前置。 | 直接使用原生平台提供的专家/模型能力。 |
| 普通专家 | 可使用 Octop 原有 Provider、模型、技能、连接器、知识库、附件和工具。 | 以智多星原生 Web 当前开放的能力为准，不承担 Octop 的本地专家编排。 |
| 托管模板 | 管理员可统一更新提示词、欢迎语、快捷问题和允许的模板技能，并发布给所有用户。 | 由智多星平台自身的专家配置和发布机制负责。 |
| 公网信息 | 可接入管理员配置的 Tavily 等搜索 Provider，把公开资料整理后交给智多星分析。 | 通常是原生平台最短链路；具体联网能力以智多星账号和产品版本为准。 |
| 多通道 | 可以把同一套用户级路由延伸到 QQ 等已接入通道。 | 以智多星原生支持的渠道为准。 |
| 用量和审计 | 可以在企业工作台按用户、专家和会话做 Token/审计统计。 | 以智多星平台的账户、套餐和用量页面为准。 |
| 内部部署 | 可部署在企业自己的测试或内网环境，数据和接入策略由企业控制。 | 由智多星平台提供 SaaS/平台侧运行环境。 |
| 原生能力更新 | 需要 AllinpayAI 适配、验证和发布后才能进入工作台。 | 原生平台通常最快获得智多星新能力。 |

## 4. 当前版本的实际优势

1. **统一治理**：管理员可以统一管理用户、专家、模型入口、搜索 Provider、模板和权限，而不是让每个用户单独维护一套入口。
2. **用户级 key 隔离**：通联发仔的调用身份与实际登录用户绑定，避免把一个公共智多星 key 暴露给所有用户。
3. **托管专家统一运营**：管理员改一次通联发仔模板，便可以版本化同步到所有用户，减少人工逐个调整。
4. **模型能力解耦**：普通专家继续使用 Octop 的 Provider/Skill/Connector 体系，通联发仔使用智多星专用直链，避免两类能力互相污染。
5. **企业工作流整合**：可以在同一工作台中承载内部知识、普通工具、业务查询和 QQ 等入口。
6. **可控的公网查询**：通过管理员配置的搜索 Provider 控制公网检索来源和费用，再把结果交给智多星做业务化归纳。

## 5. 使用边界建议

- 需要通联内部业务数据、收单业务问答和与内部业务相关的公网资料时，优先使用通联发仔。
- 需要本地技能、文件、附件、连接器、知识库或多专家协作时，使用普通专家。
- 需要验证智多星原生最新能力、套餐能力或原生插件表现时，直接使用智多星 Web 做对照验证。
- 不应把 AllinpayAI 的普通专家功能宣传成智多星原生能力，也不应把通联发仔宣传成支持 Octop 全部工具能力。
